## 🛠 Featured work

### [depview](https://github.com/ninikurshavishvili/depview)
**Why is this library in my app?** A CLI that prints the dependency tree of a Swift package or a whole Xcode project, shows what pulls each package in, and where to remove it.

`Swift 6` · `CLI` · `CI` · `Homebrew`

```bash
brew install ninikurshavishvili/tap/depview
```

### [RouteReplay](https://github.com/ninikurshavishvili/RouteReplay)
Record a GPS route once, then replay it as if it were live: in the simulator, in SwiftUI previews and in unit tests. No more walking around with your phone to test location code.

`Swift 6` · `Swift Package` · `Core Location` · `async/await` · `Tested`

An NFT explorer built on the OpenSea API, designed end to end by me in Figma ([case study on Behance](https://www.behance.net/gallery/230704837/NextNFT)).
